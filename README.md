# 요리:하다 요리공간

경북대학교 의과대학 요리 & 식문화 동아리 **요리:하다**의 요리공간 예약 · 재고 · 사용 후 체크 화면입니다.

- 접속 주소: https://jhyunpark0802.github.io/yorihada/
- 이 저장소에는 화면(정적 파일)만 있습니다. 데이터와 비밀번호는 여기에 없고, 동아리 구글 시트에 저장됩니다.
- `config.js`의 `api`는 구글 시트에 연결된 Apps Script 웹 앱 주소입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 전체 (스타일·스크립트·표제 글꼴 포함) |
| `config.js` | 서버 주소 설정 |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png`, `favicon.png` | 홈 화면 아이콘 |
| `og.png` | 링크 미리보기 이미지 |

표제 글꼴은 [Hahmlet](https://fonts.google.com/specimen/Hahmlet) (SIL Open Font License)의 일부 글자만 담아 사용합니다.
